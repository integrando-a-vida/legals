## Adicionar um novo produto

1. Crie a pasta `<produto>/` com `index.html`, `privacy-policy.html`, `terms-of-use.html` e `account-deletion.html` (copie de `stoqly/` como base).
2. Adicione o link em `index.html` na raiz e a linha na tabela acima.
3. Commit na `main` — o Pages publica automaticamente.
